Continue Playing. Investigate demonstrated behavior before changing policy.

the user's instruction to keep the current layout. No extra refresh controls,
diagnostic dashboard, input bridge, framework or speculative GPU redesign.

Read this dated continuation baseline before historical candidate narratives in
[requirements](REQUIREMENTS.md), [UX flows](UX-FLOWS.md) and
[verification](VERIFICATION.md). Their broader requirements remain; incompatible
historical descriptions are not evidence that the current product passes.

switch; unknown acquisition is not Owned; and current Library recommendations
